### How to Run Auto-Organize

1. Launch Knowledge Filesystem Agents
2. Click **"Organize"** tab
3. Click **"Select Folder"**
4. Choose the folder you want to organize
5. Select organization rules:
   - By type (images, docs, videos)
   - By date (year/month/day)
   - By content (work/personal)
6. Click **"Preview Changes"** to see before/after
7. Click **"Apply Organization"**
8. Files are moved into new folder structure

### How to Find and Remove Duplicates

1. Click **"Duplicates"** tab
2. Click **"Scan Drives/Folders"**
3. Select which drives/folders to scan
4. Choose duplicate type:
   - **Exact** (byte-for-byte)
   - **Similar Images**
   - **Similar Documents**
   - **Similar Audio**
5. Click **"Start Scan"** (may take minutes to hours)
6. Review duplicate groups
7. Select which duplicates to keep (oldest, newest, smallest, largest)
8. Click **"Remove Selected"**

### How to Use Smart Tagging

1. Click **"Tags"** tab
2. Select files or folders
3. Click **"Auto-Tag"**
4. AI analyzes content and suggests tags
5. Review and confirm suggested tags
6. Add custom tags manually if needed
7. Tags are saved to file system (NTFS metadata or sidecar files)
8. Search by tags in **"Search"** tab

### How to Use Natural Language Search

1. Click **"Search"** tab
2. Type a natural language query, for example:
   - `"pictures from my vacation in august"`
   - `"tax documents from 2025"`
   - `"videos larger than 100MB"`
   - `"files I edited last week"`
   - `"invoices for client Acme Corp"`
3. Press Enter
4. Search results appear instantly
5. Double-click to open file
6. Right-click for more options (open folder, tag, move)

### How to Create Smart Folders

1. Click **"Smart Folders"** tab
2. Click **"New Smart Folder"**
3. Create rules using AND/OR logic:
   - **Type** (Image, Document, Video, Audio, Archive)
   - **Date** (created, modified, accessed)
   - **Size** (between, larger than, smaller than)
   - **Tags** (has tag, does not have tag)
   - **Name** (contains, starts with, ends with)
   - **Content** (contains text)
4. Click **"Save"**
5. Smart folder appears in sidebar
6. Files matching rules appear automatically
7. Smart folders update in real-time

### How to Batch Rename Files

1. Select multiple files in main view
2. Right-click → **"Batch Rename"**
3. Choose rename pattern:
   - **Simple:** `document (1).txt`
   - **Date:** `2025-01-15_image.jpg`
   - **Custom:** `[prefix]_[counter].[ext]`
4. Preview new names
5. Click **"Apply"**

### How to Schedule Auto-Organization

1. Click **"Settings"** → **"Schedule"**
2. Enable **"Scheduled Organization"**
3. Choose frequency:
   - **Daily** (at specific time)
   - **Weekly** (select day + time)
   - **Monthly** (select date + time)
4. Select folders to organize
5. Select organization rules to apply
6. Click **"Save"**
7. Organization runs automatically
